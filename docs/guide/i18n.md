# 国际化

组件库默认使用简体中文（`zh-CN`），不需要额外配置。内置 `zhCN`、`enUS` 语言包，支持全局配置、运行时切换和自定义翻译，不依赖 vue-i18n。

## 安装时配置

```ts
import { createApp } from 'vue'
import XUi, { zhCN } from '@x-soft88/x-ui'
import '@x-soft88/x-ui/style.css'
import App from './App.vue'

createApp(App).use(XUi, { locale: zhCN }).mount('#app')
```

省略第二个参数时默认中文。需要英文时传入 `enUS`。

## 运行时切换与按需使用

```ts
import { setLocale, zhCN, enUS } from '@x-soft88/x-ui/locale'

setLocale(enUS)
setLocale(zhCN)
setLocale() // 恢复默认中文
```

语言配置作用于当前 JavaScript 运行环境中的所有 x-ui 组件，包括按需导入的组件和 `XMessageBox` 函数式弹窗。无需重新挂载组件；多个 Vue 应用共享此配置。SSR 应用不要用该全局入口保存不同请求的语言状态。

## 自定义文案

```ts
import { setLocale, zhCN, type XUiLocale } from '@x-soft88/x-ui/locale'

const locale: XUiLocale = {
  name: 'zh-CN',
  messages: {
    ...zhCN.messages,
    'select.placeholder': '请选择一个选项',
    'empty.description': '这里还没有内容',
    'pagination.total': '共有 {total} 条记录'
  }
}

setLocale(locale)
```

`messages` 可以只填写需要覆盖的翻译，其余条目回退到默认中文。调用 `setLocale` 会整体替换当前语言包，空字符串是有效翻译。

优先级为：组件显式传入的文案属性（包括空字符串）→ 当前语言包 → 默认中文。业务数据、选项名称和插槽内容由应用负责翻译。

## 在组合式代码中读取

```ts
import { computed } from 'vue'
import { useLocale, getLocale, translate } from '@x-soft88/x-ui/locale'

const { locale, t } = useLocale()
const totalText = computed(() => t('pagination.total', { total: 20 }))
// locale 是只读的语言名称 computed ref，随 setLocale 更新。
// getLocale() 返回当前语言包；translate 与 t 是同一翻译函数。
```

翻译应在模板、computed 或事件处理函数中调用；在 setup 顶层把翻译结果存成普通字符串，不会自动更新。

## 当前接入范围

- 选择、级联、自动补全、数字输入、开关、上传、日期时间选择器等组件的默认文案。
- 空状态、列表、表格、树表、聊天、登录、注册及部分业务组件的默认文案属性。
- 分页、日期时间面板、树节点操作、表单默认校验提示和通用浮层的操作及无障碍文字。
- Gantt 的日期表头格式默认跟随全局语言，显式指定 `locale` 时优先使用组件配置。

这次建立统一配置并接入上述文案。Gantt 设置面板、文件管理与通讯的操作及提示文案已接入统一语言入口。富文本编辑器等复杂业务界面内部仍有尚未提取的固定文案；内置中国节日及节气名称可能仍使用中文。因此 `enUS` 暂不代表所有业务界面已完整英文化。

## 手动验收

运行 `pnpm story`，打开「其它组件 / 国际化」，在「外观接口」切换语言，检查选择器占位文字、空状态、分页和确认框同步更新。给选择器输入自定义占位文字后，再次切换语言，应保留输入内容。

## API

| 导出 | 说明 |
| --- | --- |
| `zhCN` / `enUS` | 简体中文 / 英文语言包 |
| `setLocale(locale?)` | 设置全局语言包，省略时恢复中文 |
| `getLocale()` | 读取当前语言包 |
| `translate(key, params?)` | 翻译并替换 `{参数}` |
| `useLocale()` | 返回只读 `locale` 和翻译函数 `t` |
| `XUiOptions` | 插件安装选项类型，包含可选 `locale` |
| `XUiLocale` | 语言包类型：`name` 和 `messages` |
| `LocaleMessageKey` / `LocaleMessages` / `LocaleParams` | 翻译键、完整文案及参数类型 |
