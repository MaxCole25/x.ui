# x.ui

A Vue 3 UI component library foundation.

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

## Usage

```bash
pnpm add @x-soft88/x-ui
```

```ts
import { createApp } from 'vue'
import XUi from '@x-soft88/x-ui'
import '@x-soft88/x-ui/style.css'

import App from './App.vue'

createApp(App).use(XUi).mount('#app')
```
