# 甘特图第一阶段交付记录

本次按照 plan 目录的四部分方案完成 XGantt 第一阶段。遵循本次 happy path 和不新增测试用例的要求；运行仓库已有测试验证回归。Messenger 的原有未提交更改保持原样。

## 已交付

- 分类入口：`src/components/display-components/gantt/index.ts`，根入口命名导出、公开类型及 XUi 全量安装已接入。
- 内核：`src/core.ts` 中日期序号、双向坐标转换、任务索引、树展开、可见行计算、日期刻度和依赖校验独立于 Vue 与 DOM。未来资源行可以共享时间内核，不提前公开 XTimeline。
- 界面：多列表格、树层级、日周月双层表头、任务条、进度、汇总标识、里程碑、今天线、非工作日、依赖线、选中与悬停、空状态、明暗主题。
- 布局：单一滚动容器保证左右纵向位置一致，固定表头和左表，时间轴横向滚动，左表独立列浏览，列宽与分栏调整。
- 编辑：任务移动、起止调整、进度修改、一天吸附、移动阈值、边缘水平自动滚动、Esc 取消、只读和权限谓词。
- 数据：不修改 Props，异步提交前回调、失败回滚、新数组更新、保存期间编辑锁定、同任务外部更新冲突拒绝。
- 扩展：自定义列、工具栏、任务内容、里程碑、单元格、空状态、底部统计；公开方法控制定位、范围、缩放、展开和刷新。
- 演示：Histoire 唯一外观接口及统一属性、接口、类型、事件面板；20/100/1,000/10,000 任务和日期边界、空场景；正式文档使用真实 Vue 示例与折叠源码。

没有新增运行时依赖；复用现有 XButton、XEmpty、主题变量与 ApiPlayground。日期严格使用 YYYY-MM-DD，首尾包含，里程碑零工期。原生 title 提供基础悬停提示。
