# xl.ui

A Vue 3 UI component library foundation.

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

## Usage

```bash
pnpm add xl.ui
```

```ts
import { createApp } from 'vue'
import XUi from 'xl.ui'
import 'xl.ui/style.css'

import App from './App.vue'

createApp(App).use(XUi).mount('#app')
```
